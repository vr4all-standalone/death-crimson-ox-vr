# Death Crimson OX physical headset checks

Desktop/simulator evidence is in `death-validation.md`. These items remain unchecked on actual hardware.

- [ ] Install the signed Quest APK beside the existing ports; confirm its own Death Crimson icon, title and setup screen.
- [ ] Grant file access, provide the verified owned Japan Rev A and BIOS, confirm READY; remove/corrupt one required file and confirm setup explains the problem.
- [ ] Start with clean settings: **Swap P1/P2 On**, P1 left and P2 right in two-player play. Restart and confirm a changed setting persists.
- [ ] In solo play press either trigger to move the gun into that hand. Check both reload buttons and controller sleep/tracking recovery.
- [ ] Join P2 while holding either trigger; release before firing. Change Swap P1/P2 during dual play, then lose P2 while a trigger is held. Confirm no accidental extra shot or reload and each player's ammo stays with that player.
- [ ] Check both reload modes, downward reload and B/Y on both players. Shoot ten rounds, pull on empty, reload and fire again; distinguish normal damage-induced ammo refills.
- [ ] Check hit/laser alignment across the view, at HUD/menu depth, and with wider view on/off after restart.
- [ ] Check stereo separation, camera motion, world size and gun angle/size while seated and standing; verify recenter.
- [ ] Check Arcade gun, Zapper and a custom GLB; verify labels/How to play and both menu pointers.
- [ ] Enter/leave movies and every later route/boss; guns should disappear only during movie mode. Check HUD and hidden P2 prompt.
- [ ] Open the VR menu during play: simulation freezes while head motion remains live. Check system-overlay focus loss separately: guns hide and inputs release while the game continues, as in the inherited port. Confirm controls recover and Quit confirms before exiting.
- [ ] Check sustained frame rate, thermal behavior, comfort and haptic strength on Quest 2/3/3S/Pro and supported PC OpenXR runtimes.
