# Death Crimson OX VR project banner

Created with the built-in image-generation tool for the public project page and
VR4ALL catalog. This is promotional artwork, not a physical headset screenshot.

References were the Lupin VR series banner for layout and the project's own
Death Crimson OX simulator capture `dc-magazines-accept` at 106.3 seconds for
the gothic street and armored robot enemies. The generated art keeps the dark
navy grid, large title, crimson VR badge and Meta Quest / PC VR platform line.
The output was encoded as JPEG without changing its dimensions. Underlying
Death Crimson game artwork and marks remain with their respective owners.

No game ROM, BIOS, native model data or signing material is included.
